# 日记型内容系统 (LightDiary Studio)

专为创作者设计的**轻量日记型内容记录与成型工作台**。

## 🎯 核心初衷与架构设计

### 1. 为什么做这个系统？
- **日记型插队先跑，干货型后台并行**：干货型（16步流程）天然要求“反复做过验证过才敢出”，冷启动成本极高。日记型投入产出极快，先跑起来练手感。
- **练小红书表达语言**：小红书的文字节奏与标题习惯，只能靠高频、低门槛的输出练出来。
- **练拍照展示能力**：一张现成照片（书桌、笔记、电脑），是最直接的实拍练习场。
- **低成本市场调研**：日记发得快、发得多，反复测试读者对什么话题真正有反应，等做干货型时有真实反馈支撑选题（参考卡兹克重启公众号案例）。
- **沉淀方法论，防碎片化丢失**：记录决策与迭代经验，未来 AI Agent 介入时直接读取状态，无需重复口述。

## 🏗️ 三阶段闭环

1. **前阶段：按板块随时记录（素材池）**
   - 随时一句话、几秒钟记录真实卡点、小发现，绝不打断正事。
   - 快捷键 `⌘ + K` 闪念录入，支持板块分类（雅思备考、AI工作台、小红书手感、踩坑卡点、随感日常）。
2. **中阶段：固定时间整理成日记（成型工坊）**
   - 下午固定回看素材池，挑出 1~2 条。
   - **懂懂日记“拉家常”风**（3~5句话老朋友唠嗑，去爹味说教）+ **薏米风格**（一张现成实拍图配字）。
   - **📱 小红书移动端仿真卡片实时预览**：真机比例、封面配图、作者信息、互动点赞动效，实时把控小红书阅读体感。
3. **后阶段：极简发布与读者反馈复盘**
   - 保持留白原则，不过度设计。
   - 一键复制小红书格式文本。
   - 记录评论区读者高频反馈，直接反哺为后台 16 步干货工作台的硬核选题！
4. **方法论沉淀看板**：
   - 完整收录《初衷与架构设计》文档。
   - 版本演进日志（Changelog），支持随时沉淀新的迭代心得。

# 学间 · 学习手记

面向日常雅思学习的轻量记录工作台。先留下真实经历，再挑选素材整理成日记。

## 第一版范围

- 六个固定板块：单词、听力、阅读、口语、写作、其他心得。
- 随手记：文字、最多 6 张图片、自动记录时间、记住上次板块。
- 未提交内容按板块暂存于本机 IndexedDB，图片也会保留；这部分不会跨设备同步。
- 已保存记录和日记草稿按登录账号存入 D1，图片存入 R2，可跨设备读取。
- 回看整理：按板块和日期筛选、留待展开、多条记录选择、修改原始文字。
- 日记编辑：原文与草稿并排、保留素材关联、另存草稿、复制正文。
- AI 协作：复制选中素材与整理提示到已有 AI 对话，再把结果粘回。当前没有接入自动生成服务。
- 私人网站，所有数据接口和图片接口校验账号身份；不自动发布日记。

## 运行与维护

Node.js >=22.13.0。`npm ci` 安装，`npm run dev` 启动预览，`npx tsc --noEmit` 类型检查，`npm run build` 构建。

`.openai/hosting.json` 保存 Sites 身份及 DB / BUCKET 逻辑绑定。平台负责线上资源、登录和访问范围。

修改 schema 后运行 `npm run db:generate`，检查生成的 drizzle SQL。已上线迁移保持不变，只增加新迁移。

首次本地预览先构建，再用 Wrangler 把 drizzle SQL 应用到本地 D1。开发登录为框架提供的本地模拟账号，生产由平台提供登录。

## 记录原则

记录不用先有结论；疑问和未完成的尝试同样可以留下。记录与内容转化分成两个动作。原始记录不会被日记草稿覆盖。不强制每日数量，不添加积分、连续打卡或生产步骤。

## 验证与边界

以实际保存、刷新读取、图片读取、日记另存、手机布局和账号隔离为验收点。生产首次使用需要登录，真实手机登录体验还需用户设备验证。初版提供手动刷新和返回窗口时刷新，不做实时协同。
